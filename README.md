# Palak Nashik Spa — Website

A responsive, static business website for Palak Nashik Spa in Nashik, Maharashtra. Built with semantic HTML, custom CSS and vanilla JavaScript so it can be deployed directly to Cloudflare Pages or GitHub Pages without a build step.

## Features
- Responsive premium wellness design with mobile navigation
- Treatment catalogue and indicative price guide
- WhatsApp enquiry buttons and pre-filled booking enquiry form
- Click-to-call, Google Maps directions and embedded map
- FAQ accordion, photo gallery and spa ambience video modal
- SEO metadata, Open Graph tags, accessibility labels and reduced-motion support
- Cloudflare Pages-friendly security headers

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy to Cloudflare Pages
1. Sign in to Cloudflare and open **Workers & Pages → Create → Pages → Connect to Git**.
2. Select `shubhm-01/Palak-spa-nashik-`.
3. Framework preset: **None**.
4. Build command: leave blank.
5. Build output directory: `/` (repository root).
6. Deploy, then attach your domain in the Pages project settings if you control the DNS for it.

## Important operational notes
- The form opens WhatsApp with the user's enquiry. It does not store submissions, send email, charge payments, or automatically confirm appointments.
- All listed treatment prices are **indicative draft starting prices** and should be confirmed by the business before launch.
- Business opening hours are not asserted because they have not been verified.
- Stock images and the linked video are remote third-party assets. Confirm commercial usage rights and source availability before launch; replace with licensed assets or original business photos where appropriate.
- No customer reviews or unsupported business credentials are fabricated. The testimonials-like section is explicitly labelled as brand statements.
- Google Maps, WhatsApp, image, font and video resources require internet access.
